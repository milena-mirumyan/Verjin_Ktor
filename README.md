# Verjin Ktor

Verjin Ktor is an iOS mobile application developed as a capstone project to reduce food waste by connecting local bakeries with customers who are interested in purchasing unsold items at discounted prices.

## 📱 Features

- Email-based registration and login using Apple Keychain (no backend required)
- Home screen with bakery listings loaded from local JSON
- Category and keyword filtering via search and `UICollectionView`
- Favorites tab with Lottie animation for empty states
- Order summary UI styled like a physical receipt
- Product detail view with dietary tags and ingredient info
- Payment interface (mocked UI for Apple Pay / Credit Card)
- Apple Maps integration with distance-based store filtering
- Account tab with static legal/help pages (`UITableView` based)
- Adaptive layout using AutoLayout (supports iPhones and iPads)

## 🔧 Technologies Used
- Swift
- UIKit
- AutoLayout
- VIPER Architecture
- SOLID Principles
- Keychain
- Lottie (via Swift Package Manager)
- Apple Maps


## 🚧 Future Work

- Backend integration for live inventory and user accounts
- Admin panel for bakery owners
- In-app payment processing
- Push notifications and loyalty system
- Localization and multi-language support
